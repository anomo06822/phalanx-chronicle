# 戰鬥節奏與回饋優化筆記

## 結論
目前最值得持續優化的不是再加一套大型新系統，而是把現有戰鬥的 feedback loop 做得更直接、更快、更可讀。

原因很實際：
- 目前 repo 已經有 `forecast`、`status`、`VFX`、`AI`、`battle HUD` 的完整鉤子。
- 玩家已經能做出有意思的戰術決策，但資訊回饋和演出節奏有時還會拖慢理解。
- 先把 battle feedback loop 做順，再往上疊新的元素或事件系統，風險更低。

## 優先順序
1. `mana-only` 技能節奏
2. 技能演出死時間縮短
3. 技能可用性與結果資訊更直白
4. 移動 / 坐騎增益的可見性
5. 敵軍回合連續行動時的節奏壓縮

## 方向說明

### 1. `mana-only` 技能節奏
- 讓玩家只理解「這回合能不能動」和「法力夠不夠」。
- 把 cooldown 噪音抽掉之後，技能判斷成本會明顯下降。
- 這也是目前最直接影響手感的一層。

### 2. 技能演出死時間縮短
- 多目標技能最怕逐目標停頓太久。
- 目前應優先壓縮固定等待、保持 impact 清楚，但不要讓流程像在等 loading。
- 這項優化對敵軍回合尤其重要。

### 3. 技能可用性與結果資訊更直白
- action menu、selected panel、forecast、result text 應一致說明：
  - 法力是否足夠
  - 射程
  - 波及範圍
  - 實際套上的狀態與持續
- 玩家不該再從多個 panel 拼湊技能是否能放。

### 4. 移動 / 坐騎增益的可見性
- 坐騎有價值，但如果玩家看不出 `MOVE +N` 是否真的生效，系統就只是庫存數字。
- 最低限度要在 camp、selected panel、roster 都能直接看到最終移動力與 mount 摘要。

### 5. 敵軍回合連續行動時的節奏壓縮
- 當敵軍開始頻繁施法，節奏會比玩家回合更容易拖。
- 後續可以考慮：
  - 壓縮敵軍非關鍵演出
  - 合併部分重複浮字
  - 對低影響行動做更快的 camera / sequence 節奏

## 下一步建議
- 先持續沿著 battle feedback loop 做小步優化，不急著再開大型系統線。
- 等這一層穩定後，再把下一波變化元素接回 `元素 + 地形互動`，整體體驗會更扎實。
