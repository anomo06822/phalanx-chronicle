# 2D 戰棋遊戲 MVP 規格書 v0.1

## 專案目標
開發一款類似《三國英傑傳》的 2D 戰棋 / SRPG 遊戲 MVP，先完成單一關卡的可玩原型。

## MVP 成功標準
1. 進入戰鬥場景
2. 選取角色
3. 查看可移動範圍
4. 移動角色
5. 選擇攻擊
6. 對敵人造成傷害
7. 結束玩家回合
8. 觀看敵方 AI 行動
9. 達成勝利或失敗條件
10. 顯示戰鬥結果畫面

## 功能範圍
### 包含
- 方格地圖
- 玩家單位 2 名
- 敵方單位 3 名
- 回合制（玩家回合 / 敵方回合）
- 單位移動
- 單位攻擊
- 死亡判定
- 勝敗條件
- 基本 UI
- 基本敵方 AI

### 不包含
- 劇情系統
- 技能系統
- 道具系統
- 裝備系統
- 經驗與升級
- 地形加成
- 存檔 / 讀檔
- 職業與轉職
- 命中率 / 暴擊 / 反擊 / 追擊

## 地圖規格
- 地圖型式：Square Grid
- 地圖尺寸：10 x 10
- 地形種類：Plain（平地）
- 地形效果：無
- 阻擋：僅由單位佔位造成

## 角色規格
### 玩家角色
- 數量：2
- HP：30
- ATK：10
- DEF：5
- MoveRange：3
- AttackRange：1

### 敵方角色
- 數量：3
- HP：20
- ATK：8
- DEF：3
- MoveRange：3
- AttackRange：1

## 戰鬥規則
### 回合流程
玩家回合開始 → 玩家操作所有角色 → 敵方回合開始 → 敵方 AI 行動 → 回到玩家回合

### 角色行動規則
- 每個角色每回合只能行動一次
- 行動內容：移動 → 攻擊 或 等待
- 如果移動後沒有可攻擊目標，可選擇等待

### 攻擊條件
- 目標在攻擊距離內
- 目標為敵方單位
- 攻擊者本回合尚未完成行動

### 傷害公式
傷害 = max(1, 攻擊者 ATK - 防禦者 DEF)

### 死亡條件
當 HP <= 0，角色死亡並從地圖移除

## AI 規格
1. 尋找最近的玩家單位
2. 若可直接攻擊，則攻擊
3. 否則移動到距離最近的位置
4. 若移動後可攻擊，則攻擊
5. 否則等待

## 勝敗條件
### 勝利
所有敵方單位死亡

### 失敗
所有玩家單位死亡

## UI 規格
### 戰鬥 HUD
- 顯示目前回合（Player Turn / Enemy Turn）
- 顯示選中單位資訊（名稱、HP）

### 格子提示
- 藍色：可移動範圍
- 紅色：可攻擊範圍

### 行動選單
- Attack
- Wait

## 控制方式
- 平台：PC
- 輸入：滑鼠點擊
- 操作流程：
  - 點選角色
  - 點選目的地
  - 點選攻擊或等待
  - 若攻擊，點選目標
