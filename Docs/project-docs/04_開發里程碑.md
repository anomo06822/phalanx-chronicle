# 開發里程碑

## Milestone 1：專案骨架
- 建立 Unity 專案
- 建立基礎資料夾
- 建立核心類別空殼

## Milestone 2：地圖與單位
- 建立 10x10 地圖
- 建立玩家 / 敵方單位生成

## Milestone 3：移動系統
- 顯示可移動範圍
- 移動到合法格子
- 更新佔位

## Milestone 4：攻擊系統
- 顯示攻擊範圍
- 傷害結算
- 死亡移除

## Milestone 5：回合系統
- 玩家 / 敵方回合切換
- 每單位每回合行動一次

## Milestone 6：敵方 AI
- 尋找最近玩家
- 移動與攻擊

## Milestone 7：勝敗與 UI
- 勝利 / 失敗判定
- 戰鬥結果畫面
- HUD

## GitHub Project 對應建議
- 每個 Milestone 建立一張 `Epic` issue
- Epic 底下再拆 `Feature` 與 `Task`
- 所有 issue 加入同一個 GitHub Project
- Board 以 `Backlog / Ready / In Progress / Review / Done` 管理
- 詳細流程見 `08_GitHub_需求管理流程.md`
